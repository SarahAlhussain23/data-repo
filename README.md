Online Course Sales Data Cleaning

 
 data cleaning challenge project that turns messy course sales data into data ready for analysis and visualization. 

Process
Split a compound column (Course_Details) into course name and level.
Cleaned the price column by removing non-numeric characters using Regular Expressions.
Converted invalid rating values into processable values and removed duplicates.
Detected outliers: ratings outside the valid range (0–5) and future enrollment dates.
Engineered new features: "Discounted / Full Price" and "High Rating / Normal".
